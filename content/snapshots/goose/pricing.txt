Open Intelligence Kit (oi-kit) and goose
Build agents that run anywhere with oi-kit.
oi-kit provides the reusable Rust components for building agents. goose is a complete agent built with oi-kit: use its desktop app or CLI, or make it the agent backend for your own application over ACP.
Both live in this repository. goose is part of the Agentic AI Foundation (AAIF) at the Linux Foundation.
Build with oi-kit
Compose an agent from a state machine, operations, tools, model providers, and context management. Your application owns the interface, policies, and storage.
Control how the agent works. Compose operations for tool execution, approvals, compaction, and your application's own behavior.
Resume from saved state. Supply your own storage and let the state machine determine what to do next from the persisted conversation.
Run in different environments. Use the core runtime in native applications, on servers, or in WebAssembly hosts.
Run models in-process. Load supported local models directly, without Ollama or a separate inference server, with control over model loading and inference.
Rust exposes the full agent runtime. Python and Kotlin bindings currently cover model providers, streaming, and conversation compaction. oi-kit is in alpha; use the documentation version that matches your dependencies.
Getting Started — build a small Rust agent with tools, streaming, and a saved conversation.
Demos — explore working applications and their source code.
Concepts — understand the state machine, operations, providers, and authentication.
Reference — choose crates and find generated Rust, Python, and Kotlin API documentation.
Use goose
goose is a general-purpose agent for coding, research, writing, automation, and data analysis. Use the native desktop app on macOS, Linux, or Windows, or work from the terminal with the CLI. Connect tools and data through the Model Context Protocol (MCP) .
Load local models directly inside goose, without a separate model server, or connect to over 85 providers , including Anthropic, OpenAI, Gemini, OpenRouter, and Amazon Bedrock.
Download the desktop app for macOS, Linux, and Windows.
Or install the CLI:
curl -fsSL https://github.com/aaif-goose/goose/releases/download/stable/download_cli.sh | bash
Then follow the goose Quickstart to configure a model and start a session.
Build an app over ACP
Use the pre-built goose binary as the agent behind your own application through the Agent Client Protocol (ACP) . Start it as a subprocess:
goose acp
Your app sends prompts and receives streamed responses, tool activity, and permission requests. goose supplies the agent, model connections, tools, and saved conversations; your app owns the interface and workflow. This is also how goose Desktop talks to its backend.
Follow Build an app over ACP for a working client example, then consult the ACP extensions reference for goose-specific capabilities.
