Agent Modes
Agent Modes let you choose the balance between included allowance, credits, and capability before you send a request. Open the Agent settings dropdown in the prompt box, then select the mode that fits the work.
Economy Mode is no longer available. Power Mode replaces it at the same price.
Choose Free Mode from the mode selector.
​
Choose a mode
Free Mode: Explore ideas, ask questions, start building, and keep everyday work moving. Free Mode uses intelligent model routing to select the model.
Power Mode: A smart balance of speed and capability for most work. Use it when you need more than your Free Mode allowance or want a stronger default for an existing project.
Max Mode: The most capable option for complex, ambitious work, larger codebases, and harder problems.
Power Mode and Max Mode use monthly credits. Replit lets you know before a request shifts from Free Mode to a mode that incurs usage costs. Check your remaining Free Mode allowance in Settings → Usage . For practical tips, see Get the most out of Free Mode .
Routines run in Power or Max Mode and require a per-run budget. They cannot run in Free Mode. Learn more about Routines .
