Get Started
Download and Install
Download MiniMax Code and install it on macOS or Windows.
MiniMax Code supports macOS and Windows. After installation, sign in with your MiniMax account to start creating tasks.
​
Download
Global site
Recommended for users outside mainland China.
China site
Recommended for mainland China network environments.
​
Requirements
Platform Requirement
macOS macOS 12 Monterey or later
Windows Windows 10 or later
​
Install Steps
1
Download the installer
Choose the package that matches your device. Use arm64 for Apple silicon Macs and x64 for Intel Macs.
2
Install the app
On macOS, open the .dmg and drag the app into Applications. On Windows, run the installer and follow the prompts.
3
Sign in
Launch MiniMax Code and sign in with your MiniMax account.
4
Keep it updated
The app will notify you when a new version is available. You can also check for updates in settings.
​
Installation Troubleshooting Find the entry that matches the message you see. If there is no error message, or the app closes as soon as it opens, see “The App Still Won’t Start” below.
​
macOS
The app isn't compatible with this version of macOS
Check your macOS version first, then make sure you downloaded the right installer for your Mac.
Open Apple menu › About This Mac . The current release requires macOS 12 Monterey or later; macOS 11 Big Sur is not supported.
Check the Chip or Processor field. Choose arm64 for an Apple M-series chip, or x64 for an Intel processor.
To update macOS, go to System Settings › General › Software Update . On older versions, go to System Preferences › Software Update .
If your Mac cannot upgrade to a supported version of macOS, downloading the installer again will not resolve the compatibility issue.
The app is “damaged and can't be opened”
macOS has detected that the app has been modified or damaged. Start with a fresh copy from the official download page to rule out an outdated or incomplete download.
Quit MiniMax Code and move the app from Applications to the Trash. Remove only the app; keep your local app data.
Use the official links in the Download section above to download the correct installer for your Mac. Do not reuse the old .dmg file.
Once the download finishes, open the .dmg, drag MiniMax Code into Applications , and launch it from there.
If the same warning appears, save the installer filename and the full warning message, then follow “Still Need Help?” below. Avoid repeated reinstalls, changing the app’s signature in Terminal, or disabling macOS security checks.
macOS reports malware, says the app “will damage your computer,” or moves it to the Trash
Do not use the Open Anyway steps in the next entry for these warnings. Some older MiniMax Code releases were blocked because of a signing certificate issue. The maintainers re-signed and replaced the affected installers. Similar warnings can have other causes, so do not assume every warning is a false positive.
Stop using the blocked copy. Do not restore it from the Trash.
Download a fresh installer from the official links above, drag the app into Applications , and try again.
If macOS also blocks the fresh copy, save a screenshot of the warning and the installer filename. Report the issue using the options below and wait for it to be investigated.
Do not disable system protection or re-sign the app yourself. For the resolved certificate issue, see GitHub Issue #95 .
The developer cannot be verified, or Apple cannot check the app for malicious software
macOS cannot verify the developer or the app’s notarization. This message alone does not establish a network problem. Before proceeding, confirm that the installer came from an official download link above and has not been modified.
Dismiss the warning with Done or Cancel .
Open System Settings › Privacy & Security and scroll to Security .
Find the notice that MiniMax Code was blocked and click Open Anyway .
Authenticate with your Mac login password if prompted, then click Open .
On macOS 12, use System Preferences › Security & Privacy › General instead. If Open Anyway is unavailable, your Mac is managed by your organization, or you cannot confirm that the installer is trustworthy, contact your IT administrator or use the support options below.
​
Windows
“Windows protected your PC” appears
This is a Microsoft Defender SmartScreen reputation warning. A newly released installer may not yet have enough download history to be recognized. This warning is different from an antivirus alert identifying a specific threat.
Confirm that you downloaded the installer from an official link above, then click More info to check the app name and publisher.
If you trust the source and publisher, click Run anyway .
If the publisher is unknown, the details do not match what you expect, or Run anyway is unavailable, stop and use the support options below. On an organization-managed PC, contact your IT administrator; your organization’s policy may restrict installation.
Security software quarantines or deletes the installer
Check which security tool blocked the file and what it detected. Do not disable protection or add an exclusion for the entire installation folder.
For Microsoft Defender, open Windows Security › Virus & threat protection › Protection history . For another security tool, check its quarantine or detection history.
Open the relevant entry and save the threat name, the blocked file’s path, and a screenshot.
Report these details using the support options below. Once the detection is confirmed to be a false positive, follow the security tool’s or your IT administrator’s instructions to restore the affected file and reinstall.
Downloading the same installer repeatedly will usually trigger the same block until the cause is addressed. If there is no record of a blocked file, continue with “The App Still Won’t Start” below.
Signing in doesn't open a browser
If you see “Unable to open a browser,” an error containing 0x800401F5 , or no_default_browser , check your default browser settings.
Make sure a browser such as Edge or Chrome is installed and can open web pages.
On Windows 11, open Settings › Apps › Default apps , select your browser, and click Set default . On Windows 10, choose a browser under Settings › Apps › Default apps › Web browser .
Reopen MiniMax Code and try signing in again.
If the browser opens but the sign-in page fails, or you are not returned to the app after signing in, this fix does not apply. Save the message shown in the browser and report it using the options below.
​
The App Still Won’t Start
Nothing happens, the app closes immediately, or a service fails to start
These symptoms can have different causes. Start with the checks below before assuming the problem is related to the installation location or your network.
Check the requirements above. On macOS, also make sure you moved MiniMax Code into Applications and are launching it from there.
Save your work, restart your computer, and try opening MiniMax Code again to clear any leftover processes.
If you are using an older release, or the problem started after an update, download and install the current release from the official links above. Do not manually delete MiniMax Code’s local settings or conversation data.
If the problem persists, note whether no window appears, a window opens and immediately closes, or a service fails to start. Include the full text of any error when reporting the issue.
On Windows, if no error dialog appears, open Event Viewer › Windows Logs › Application and look for an error related to MiniMax Code at the time of the failure. Include the Faulting module name and Exception code , if available. A crash alone does not identify a graphics driver, permissions, or app defect as the cause.
​
Still Need Help?
If the app opens: Follow the Feedback instructions. Include a log upload ID if you can upload logs.
If you cannot install or open the app: Open the GitHub issue form in your browser. Sign in to GitHub, choose Bug report , and select Startup / install / update as the issue type. If you cannot upload logs, enter cannot upload in the Upload ID field.
If you prefer community support: Visit the Discord community section on the Welcome page . You do not need to open MiniMax Code first.
Include your operating system version, chip or processor, installer filename, a screenshot of the full error, and the steps you have already tried. If you cannot open the app to check its version, provide the installer filename and say that the app will not open. GitHub issues are public, so redact account details, API keys, and private file information from screenshots and logs before posting.
