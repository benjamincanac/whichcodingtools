Custom Agents
Create dedicated Agents with their own role, instructions, skills, workspace, and channels.
Create custom Agents for recurring roles such as coding assistant, research assistant, documentation assistant, or project helper.
Each Subagent can have its own conversation entry. Start a dedicated chat from the Agent configuration page, and the selected Agent will work from the instructions you set for that role.

How to Use Create Agents from the Agent Team area in the sidebar. After creation, open that Agent’s dedicated conversation from the sidebar or Agent configuration page, and adjust profile, model, and channels in settings. Dedicated conversations are useful when one role should repeatedly handle the same type of work, such as a documentation Agent for release notes, a research Agent for source gathering, or a review Agent for checking code changes.
