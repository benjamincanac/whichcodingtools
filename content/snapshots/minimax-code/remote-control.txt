Remote Control
Connect to your desktop Agent from your phone to check progress, add instructions, and approve permissions.
Remote Control lets you connect to a running MiniMax Code desktop app from your phone. It is designed for following long tasks after you leave your computer.
​
What You Can Do
Check task progress
Send follow-up instructions
Approve permission requests
View task outputs and selected file content
​
How to Use Open Remote Control in the desktop app and follow the pairing instructions. Once connected, your phone can stay linked to the desktop conversation.
