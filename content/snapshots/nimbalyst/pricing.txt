FAQ
Frequently Asked Questions
What's included in the free Individual plan?
Everything you need for personal use: the full Nimbalyst editor, session manager, Claude Code and Codex AI integration, MCP server support, extensions, file link sharing, mockups, diagrams, data models, and git worktrees. No feature limits, no trial period. Do I need my own API key or subscription for AI features?
Yes. You bring your own AI access and Nimbalyst provides the workspace and tools around it. Your access can be a subscription like Claude Code or Codex, an API key from Anthropic, OpenAI, or other providers, or local models through LM Studio. Nimbalyst connects to whichever you already have. See how Claude Code and Codex access works &rarr;
What does the Teams plan add?
The Teams plan adds real-time collaboration: edit shared docs, mockups, and diagrams together, manage tasks and trackers as a team with your agents working the same board, and control workspace access with admin tools. How much does Teams cost?
Teams is $20 per user per month, or $200 per user per year. Teams is in Beta right now and free to use while it is, so you can bring your whole team in and try collaboration on real work before you pay anything. How do we get into the Teams Beta?
Download Nimbalyst, sign in, and create a team from the app. Invite your teammates by email and shared docs, trackers, and boards work across everyone immediately. No approval step and no card required.
