Security and compliance readiness
Orca keeps agent work inside the engineering systems your team already trusts: local workspaces, git history, pull requests, and approved model providers.
AICPA SOC 2 Readiness
No silent changes
Every agent change lands in a worktree and a pull request, so it is reviewed the same way as human code.
Audit trail by default
Git history, pull requests, and workspace activity record who ran what, where, and when.
Your providers, your keys
Agents talk to the model providers and CLIs your team already approves. Orca never sits in the middle.
Rollout guidance
We help teams standardize on approved agents, integrations, and organization-level defaults.
Designed around your existing workflow
Nothing new to trust. Orca runs where your code already lives and talks to the providers you already pay for.
Local-first
Repositories, worktrees, terminals, and agent sessions run on machines you control.
Self-hostable
Orca is open source. Run the desktop app, an always-on Orca server, or both inside your own network.
No model in the middle
Prompts and code go straight to the providers you configure. Orca does not inspect or store them.
