No more approval fatigue 06A
No more approval fatigue / 06
No more approval fatigue
The utility model can be configured to act as a first pass for all permission requests that would otherwise come to you. It will follow the exact permission policy you give it, and approve the request when safe, escalate to you when unsafe. Auto-approvals will leave an entry in transcript along with approval reason.

Anchored file editing / 07
Anchored file editing
Dirac uses a custom hash-anchoring protocol that makes code editing extremely efficient. Instead of using search-replace, it uses stable line anchors so model can say 'replace the text between anchor X and anchor Y with this new text'.

AST code inspection 08A
AST code inspection / 08
AST code inspection
Dirac leverages the underlying syntax trees to perform precise code inspection. For example, model can use inspect_ast('outline', 'utils/db.py') to get all classes and methods defined in a list of files, inspect_ast('implementation', 'utils/db.py', 'DBManager::init_db()') to extract a single method.
DIRAC / AST code inspection 08B
AST code manipulation 09A
AST code manipulation / 09
AST code manipulation
Dirac can replace a function like edit_ast('replace, 'utils/db.py', 'replacement', '{code}') or rename 100s of symbol like edit_ast('rename', 'src/', 'old_name', 'new_name') in one call.

Concurrent subagents / 11
Concurrent subagents
Subagents are a first class citizens that can do (almost) everything the main task can do. Dirac's infra detects any file staleness at edit time. The subagents can have their own tools, prompts, timeouts and can inherit the context from parent.
